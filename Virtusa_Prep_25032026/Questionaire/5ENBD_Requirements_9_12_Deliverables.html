Req 9DataFrame Best Practices

9.1 — GROUP TRANSFORMATIONS LOGICALLY

Never scatter withColumn calls across separate reassignments. Each reassignment creates a new DataFrame object and produces a harder-to-read execution plan. Group related transformations into a single chained expression, separated by a comment that names the logical group.

✗ Anti-pattern — scattered assignments
# 4 separate DFs created — messy plan
df = df.withColumn("txn_category", ...)
df = df.withColumn("risk_flag", ...)
df = df.withColumn("_load_ts", ...)
df = df.withColumn("_pipeline_run", ...)
✓ Correct — logically grouped chain
# Group 1: business rules  Group 2: audit cols
df = (df
    # ── Business classification ──────────────
    .withColumn("txn_category", ...)
    .withColumn("risk_flag", ...)
    # ── Audit metadata ───────────────────────
    .withColumn("_load_ts",       current_timestamp())
    .withColumn("_pipeline_run",  lit(self.run_date))
)

9.2 — USE EXPLICIT SCHEMAS (NEVER inferSchema ON PRODUCTION READS)

Inferring schema from JDBC or file reads triggers an extra full scan to guess types — expensive and unreliable for nullable Decimal columns and Oracle DATE types. Define schemas as class-level constants so they are reusable, testable, and serve as living documentation.

from pyspark.sql.types import (

    StructField, StructType, TimestampType,

# ── Defined at class level — reusable in tests and pipelines ──
TXN_SOURCE_SCHEMA = StructType([

9.3 — NEVER USE select(*)

Wildcards bypass Catalyst's column pruning optimisation, causing unnecessary I/O on columnar Delta files. They also make schema drift invisible — a new column added at the source silently flows downstream.

✗ select(*) — reads all columns
result = df.select("*")

# Also bad: implicit wildcard after join
result = txn_df.join(branch_df, "branch_id")
result.show()  # contains all cols from both DFs
✓ Explicit column selection always
# Canonical output — mirrors SILVER_OUTPUT_SCHEMA
result = enriched_df.select(
    col("TXN_ID").alias("txn_id"),
    col("CUSTOMER_ID").alias("customer_id"),
    col("AMOUNT").alias("amount"),
    col("STATUS").alias("txn_status"),
    col("TXN_DATE").alias("txn_date"),
    col("txn_category"),
    col("branch_name"),
    col("region"),
    col("_load_ts"),
    col("_pipeline_run"),
)

9.4 — OPTIMISE JOINS: ALIASES + BROADCAST HINTS

Three rules for production joins: (1) always alias both sides to remove column ambiguity, (2) use broadcast() for any dimension table under 20 MB, (3) filter dimension tables before the join — never join then filter.

from pyspark.sql.functions import broadcast, col

# ── BAD: no alias, no broadcast, no pre-filter ─────────────────────
result = transactions.join(branches, "branch_id").join(customers, "customer_id")

# ── GOOD: alias both sides + broadcast small dims ──────────────────

# Step 1: Pre-filter dims BEFORE join (reduce join input)
active_branches = (
    branch_df
    .filter(col("is_active") == True)
    .select("branch_id", "branch_name", "region")  # only needed cols
    .alias("b")
)
active_customers = (
    customer_df
    .filter(col("status") == "ACTIVE")
    .select("customer_id", "customer_name", "risk_tier")
    .alias("c")
)

# Step 2: alias transaction DF + broadcast both small dims
result = (
    txn_df.alias("t")
    .join(
        broadcast(active_branches),               # branches ~500 rows → broadcast
        on=col("t.BRANCH_ID") == col("b.branch_id"),
        how="left",
    )
    .join(
        broadcast(active_customers),              # customers filtered before join
        on=col("t.CUSTOMER_ID") == col("c.customer_id"),
        how="inner",                            # only active customers
    )
    .select(
        col("t.TXN_ID").alias("txn_id"),       # fully qualified — no ambiguity
        col("t.AMOUNT").alias("amount"),
        col("b.branch_name"),
        col("b.region"),
        col("c.risk_tier"),
    )
)
Req 10Connection Management

10.1 — SECURE CREDENTIAL HANDLING

Credentials must never appear in code, environment variables, or log output. In a Databricks environment, the approved pattern is Databricks Secrets backed by Azure Key Vault. Outside Databricks (e.g. Spark on Kubernetes), use the Azure Key Vault SDK with Managed Identity.

# ── Pattern 1: Databricks Secrets (production standard for ENBD/Virtusa) ──

def _load_credentials(self) -> None:
    """
    Load sensitive credentials from Databricks Secret Store (Azure Key Vault backed).
    Credentials are NEVER logged, stored in variables with long lifetime,
    or passed as constructor arguments in plain text.
    """
    # dbutils.secrets.get() returns the secret value but masks it in all Spark logs
    self.config["db_password"] = dbutils.secrets.get(
        scope="kv-enbd-prod",
        key="oracle-etl-svc-password"
    )

# ── Pattern 2: Azure Key Vault SDK (non-Databricks environments) ──
from azure.identity import DefaultAzureCredential
from azure.keyvault.secrets import SecretClient

def _load_credentials_sdk(self, vault_url: str) -> None:
    """Use Managed Identity — no client secret needed in code."""
    credential = DefaultAzureCredential()   # picks up MSI/Service Principal automatically
    client = SecretClient(vault_url=vault_url, credential=credential)
    self.config["db_password"] = client.get_secret("oracle-etl-svc-password").value

# ── What NOT to do ────────────────────────────────────────────────────────
# BAD: hardcoded credential
# password = "P@ssw0rd123"
#
# BAD: environment variable (readable in process list + CI logs)
# password = os.environ["DB_PASSWORD"]
#
# BAD: passed through __init__ as plain text
# etl = CustomerTransactionETL(spark, config={"db_password": "secret"})

10.2 — REUSABLE CONNECTION PROPERTIES

JDBC properties are computed once and cached — not rebuilt on every call. The _jdbc_props instance variable is None until first access, then reused for all subsequent JDBC reads in the same pipeline run.

class CustomerTransactionETL:
    def __init__(self, spark, config):
        self._jdbc_props: Optional[Dict[str, str]] = None   # lazy — not built yet
        # ... other init

    def _setup_jdbc_properties(self) -> Dict[str, str]:
        """Return cached JDBC properties. Build once, reuse always."""
        if self._jdbc_props is None:
            self._jdbc_props = {
                "url":             self.config["oracle_jdbc_url"],
                "driver":          "oracle.jdbc.OracleDriver",
                "user":            self.config["db_user"],
                "password":        self.config["db_password"],
                "fetchsize":       "5000",
                "numPartitions":   "20",
                "partitionColumn": "TXN_ID",
                "lowerBound":      "1",
                "upperBound":      "1000000000",
                # Timezone: force UTC to prevent Oracle DATE → Spark TIMESTAMP drift
                "sessionInitStatement": "ALTER SESSION SET TIME_ZONE='UTC'",
            }
        return self._jdbc_props  # same dict object on all subsequent calls

    def _load_source_data(self, last_wm: str) -> DataFrame:
        # Reuse — no dict reconstruction
        jdbc_props = self._setup_jdbc_properties()
        return spark.read.format("jdbc").options(**jdbc_props).load()

    def _load_reference_table(self, table: str) -> DataFrame:
        # Same cached props reused for a different query
        jdbc_props = self._setup_jdbc_properties()
        return spark.read.format("jdbc").option("dbtable", table).options(**jdbc_props).load()

10.3 — PROPER CLEANUP OF SPARK AND JDBC CONNECTIONS

SparkSession must be stopped in a finally block to release executor memory and cluster resources. JDBC connections are managed by the Spark JDBC driver pool — they are released automatically when the DataFrame action completes, but SparkSession.stop() ensures the connection pool is flushed.

# ── CLI entry point with guaranteed SparkSession cleanup ───────────────
def main() -> None:
    """
    Entry point for standalone execution.
    Guarantees SparkSession cleanup via try/finally regardless of outcome.
    """
    spark: Optional[SparkSession] = None
    try:
        spark = (
            SparkSession.builder
            .appName("CustomerTransactionETL")
            .config("spark.sql.extensions", "io.delta.sql.DeltaSparkSessionExtension")
            .config(
                "spark.sql.catalog.spark_catalog",
                "org.apache.spark.sql.delta.catalog.DeltaCatalog",
            )
            .getOrCreate()
        )
        config = _build_config(spark)
        etl = CustomerTransactionETL(spark, config)
        etl.run_etl_pipeline()

    except Exception as exc:
        logger.error("Pipeline failed: %s", exc)
        raise                  # re-raise so ADF activity shows FAILED status

    finally:
        if spark is not None:
            spark.stop()       # always runs — flushes JDBC pool + releases executors
            logger.info("SparkSession stopped.")


# ── Context manager pattern (alternative for frameworks that provide Spark) ──
from contextlib import contextmanager
from typing import Iterator

@contextmanager
def managed_spark_session(app_name: str) -> Iterator[SparkSession]:
    """Context manager that guarantees SparkSession cleanup on exit."""
    spark = SparkSession.builder.appName(app_name).getOrCreate()
    try:
        yield spark
    finally:
        spark.stop()

11.2 — MAINTAIN SAME OUTPUT SCHEMA

Define the Silver output schema as a class-level constant (SILVER_OUTPUT_SCHEMA) and enforce it at the end of _combine_and_finalize_data. This makes schema drift a test failure, not a silent production bug.

# Class-level schema constant — the contract with downstream consumers
SILVER_OUTPUT_SCHEMA = StructType([
    StructField("txn_id",        StringType(),        nullable=False),
    StructField("customer_id",   StringType(),        nullable=False),
    StructField("amount",         DecimalType(18,2),  nullable=False),
    StructField("txn_status",     StringType(),        nullable=True),
    StructField("txn_date",       DateType(),           nullable=True),
    StructField("txn_category",   StringType(),        nullable=False),
    StructField("branch_name",    StringType(),        nullable=True),
    StructField("region",          StringType(),        nullable=True),
    StructField("_load_ts",        TimestampType(),     nullable=False),
    StructField("_pipeline_run",  StringType(),        nullable=False),
])

def _combine_and_finalize_data(self, txn_df, branch_df):
    enriched_df = txn_df.alias("t").join(
        broadcast(branch_df.alias("b")),
        col("t.BRANCH_ID") == col("b.branch_id"),
        "left"
    )
    # Explicit select enforces schema contract — no drift possible
    final_df = enriched_df.select(
        col("t.TXN_ID").alias("txn_id"),
        col("t.CUSTOMER_ID").alias("customer_id"),
        col("t.AMOUNT").alias("amount"),
        col("t.STATUS").alias("txn_status"),
        col("t.TXN_DATE").alias("txn_date"),
        col("txn_category"),
        col("b.branch_name"),
        col("b.region"),
        col("_load_ts"),
        col("_pipeline_run"),
    )
    # Schema assertion in test: final_df.schema == SILVER_OUTPUT_SCHEMA
    return final_df

class CustomerTransactionETL:
    """
    End-to-end incremental ETL for ENBD customer transaction data.

    Orchestrates Oracle JDBC extraction → validation → deduplication
    → transformation → branch enrichment → Delta Lake Silver persistence.
    All external dependencies (credentials, paths) are injected via the
    config dict; no hardcoded values exist in this class.

    Attributes:
        spark       (SparkSession)   : Active Spark session.
        config      (Dict[str,str])  : Pipeline configuration.
        run_date    (str)            : Processing date YYYY-MM-DD.
        _jdbc_props (Dict[str,str])  : Lazily cached JDBC connection props.

    Example:

        etl.run_etl_pipeline()

    _VALID_STATUSES: Tuple[str, ...] = ("COMPLETED", "PENDING", "FAILED")

    def __init__(self, spark: SparkSession, config: Dict[str, str]) -> None:
        """
        Initialise ETL with Spark session and validated configuration.

        Args:
            spark  (SparkSession)   : Active SparkSession.

        self._validate_config(config)
        self.spark:       SparkSession         = spark
        self.config:      Dict[str, str]       = config
        self.run_date:    str                  = datetime.today().strftime("%Y-%m-%d")
        self._jdbc_props: Optional[Dict[str, str]] = None
        self._setup_logging()

    # ──────────────────────────────────────────────────────────────────────
    # SETUP METHODS
    # ──────────────────────────────────────────────────────────────────────

    def _setup_logging(self) -> None:
        """Configure module-level logger with ISO-format timestamps."""
        if not logger.handlers:
            h = logging.StreamHandler()
            h.setFormatter(logging.Formatter(
                "%(asctime)s [%(levelname)-8s] %(name)s: %(message)s",
                datefmt="%Y-%m-%d %H:%M:%S",
            ))
            logger.addHandler(h)
            logger.setLevel(logging.INFO)

    def _setup_spark_config(self) -> None:
        """
        Apply AQE and performance-optimised Spark settings.

        All settings are idempotent — safe to call multiple times.
        AQE enables: partition coalescing, skew-join splitting,
        and runtime join strategy switching.
        """
        conf_pairs: List[Tuple[str, str]] = [
            ("spark.sql.adaptive.enabled",                      "true"),
            ("spark.sql.adaptive.coalescePartitions.enabled",    "true"),
            ("spark.sql.adaptive.skewJoin.enabled",              "true"),
            ("spark.sql.adaptive.advisoryPartitionSizeInBytes",   "134217728"),
            ("spark.sql.shuffle.partitions",                      "400"),
            ("spark.sql.autoBroadcastJoinThreshold",              "20971520"),
        ]
        for key, value in conf_pairs:
            self.spark.conf.set(key, value)
        logger.info("Spark configuration applied.")

    def _setup_jdbc_properties(self) -> Dict[str, str]:
        """
        Build and cache JDBC connection properties for Oracle source.

        Properties are initialised once on first call and reused across
        all subsequent JDBC reads to avoid repeated dict construction.

        Returns:
            Dict[str,str]: JDBC driver properties including parallel read settings
                           and UTC session timezone to prevent date drift.
        """
        if self._jdbc_props is None:
            self._jdbc_props = {
                "url":              self.config["oracle_jdbc_url"],
                "driver":           "oracle.jdbc.OracleDriver",
                "user":             self.config["db_user"],
                "password":         self.config["db_password"],
                "fetchsize":        str(self._JDBC_FETCH_SIZE),
                "numPartitions":    str(self._JDBC_PARTITIONS),
                "partitionColumn":  "TXN_ID",
                "lowerBound":       "1",
                "upperBound":       "1000000000",
                # Force UTC to prevent Oracle local-timezone → UTC drift on DATE cast
                "sessionInitStatement": "ALTER SESSION SET TIME_ZONE='UTC'",
            }
        return self._jdbc_props

    def _validate_config(self, config: Dict[str, str]) -> None:
        """
        Assert all required configuration keys are present.

        Args:
            config (Dict[str,str]): Configuration to validate.
        Raises:
            ValueError: Lists all missing keys in a single error.
        """
        required: List[str] = [
            "oracle_jdbc_url", "db_user", "db_password",
            "watermark_path",  "silver_path", "quarantine_path",
            "branch_table",
        ]
        missing = [k for k in required if k not in config]
        if missing:
            raise ValueError(f"Missing required config keys: {missing}")

    # ──────────────────────────────────────────────────────────────────────
    # LOAD METHODS
    # ──────────────────────────────────────────────────────────────────────

    def _load_watermark(self) -> str:
        """
        Read last successfully processed timestamp from metadata Delta table.

        Returns:
            str: ISO timestamp string. Returns _DEFAULT_WATERMARK on first run.
        """
        try:
            rows = (
                self.spark.read.format("delta")
                .load(self.config["watermark_path"])
                .filter(col("table_name") == self._TABLE_NAME)
                .select("last_processed_ts")
                .collect()
            )
            wm = str(rows[0][0]) if rows else self._DEFAULT_WATERMARK
        except Exception:  # noqa: BLE001 — tolerant first-run behaviour
            wm = self._DEFAULT_WATERMARK
        logger.info("Loaded watermark: %s", wm)
        return wm

    def _load_source_data(self, last_wm: str) -> DataFrame:
        """
        Incrementally extract transaction records from Oracle via JDBC.

        Applies server-side WHERE predicate to limit rows to those modified
        after last_wm, reducing network transfer to incremental delta only.

        Args:
            last_wm (str): Watermark timestamp — rows with LAST_UPDATED > last_wm.
        Returns:
            DataFrame: Raw incremental Oracle records with TXN_SOURCE_SCHEMA.
        Raises:
            RuntimeError: Wraps JDBC exceptions with watermark context for diagnosis.
        """
        push_down = (
            f"(SELECT * FROM CORE_TRANSACTIONS WHERE LAST_UPDATED > "
            f"TO_TIMESTAMP('{last_wm}','YYYY-MM-DD HH24:MI:SS')) T"
        )
        try:
            raw_df = (
                self.spark.read.format("jdbc")
                .option("dbtable", push_down)
                .schema(TXN_SOURCE_SCHEMA)  # explicit — no inference scan
                .options(**self._setup_jdbc_properties())
                .load()
            )
            logger.info("Extracted %d rows from Oracle (wm=%s).", raw_df.count(), last_wm)
            return raw_df
        except Exception as exc:
            raise RuntimeError(
                f"JDBC extraction failed for watermark={last_wm}: {exc}"
            ) from exc

    def _load_branch_reference(self) -> DataFrame:
        """
        Load and return branch master dimension for enrichment join.

        Returns:
            DataFrame: Columns (branch_id, branch_name, region) — caller
                       should apply broadcast() when joining.
        """
        branch_df = (
            self.spark.table(self.config["branch_table"])
            .select("branch_id", "branch_name", "region")
        )
        logger.info("Loaded %d branch reference rows.", branch_df.count())
        return branch_df

    # ──────────────────────────────────────────────────────────────────────
    # PROCESS METHODS
    # ──────────────────────────────────────────────────────────────────────

    def _process_validate(self, df: DataFrame) -> Dict[str, DataFrame]:
        """
        Apply data quality rules; route records to valid or quarantine sets.

        Each failing record is tagged with a pipe-separated string of error
        codes indicating every violated rule, enabling targeted reprocessing.

        Args:
            df (DataFrame): Raw Bronze-layer records.
        Returns:
            Dict[str,DataFrame]: Keys 'valid' and 'quarantine'.
                valid      — Records passing all quality rules; error_codes dropped.
                quarantine — Records failing ≥1 rule; includes error_codes column.
        """
        tagged = df.withColumn(
            "_errors",
            array(
                when(col("TXN_ID").isNull(),                              lit("NULL_TXN_ID")),
                when(col("CUSTOMER_ID").isNull(),                         lit("NULL_CUSTOMER_ID")),
                when(col("AMOUNT") <= 0,                                  lit("NON_POSITIVE_AMOUNT")),
                when(col("BRANCH_ID").isNull(),                           lit("NULL_BRANCH_ID")),
                when(~col("STATUS").isin(*self._VALID_STATUSES),          lit("INVALID_STATUS")),
            ),
        ).withColumn(
            "error_codes",
            concat_ws("|", array_filter("_errors", lambda x: x.isNotNull())),
        ).drop("_errors")

        valid_df      = tagged.filter(col("error_codes") == "").drop("error_codes")
        quarantine_df = tagged.filter(col("error_codes") != "")
        logger.info(
            "Validation: %d valid, %d quarantined.",
            valid_df.count(), quarantine_df.count()
        )
        return {"valid": valid_df, "quarantine": quarantine_df}

    def _process_deduplicate(self, df: DataFrame) -> DataFrame:
        """
        Remove duplicate records keeping the most recently ingested version.

        Uses row_number() window partitioned by TXN_ID, ordered by _load_ts
        descending — deterministic deduplication even with concurrent writes.

        Args:
            df (DataFrame): Validated records with _load_ts column.
        Returns:
            DataFrame: One row per TXN_ID (latest ingestion wins).
        """
        win = Window.partitionBy("TXN_ID").orderBy(col("_load_ts").desc())
        result = (
            df.withColumn("_rn", row_number().over(win))
            .filter(col("_rn") == 1)
            .drop("_rn")
        )
        logger.info("Dedup: %d → %d rows.", df.count(), result.count())
        return result

    def _process_transform(self, df: DataFrame) -> DataFrame:
        """
        Apply business transformation rules to produce Silver-ready attributes.

        Transformations are grouped logically:
            Group 1 — Business classification rules
            Group 2 — Audit and lineage metadata columns

        Args:
            df (DataFrame): Deduplicated validated records.
        Returns:
            DataFrame: Input records plus txn_category, _load_ts, _pipeline_run.
        """
        return (
            df
            # ── Group 1: Business classification ────────────────────────────
            .withColumn(
                "txn_category",
                when(col("AMOUNT") >= self._HIGH_VALUE_THRESHOLD, lit("HIGH_VALUE"))
                .otherwise(lit("STANDARD")),
            )
            # ── Group 2: Audit metadata ─────────────────────────────────────
            .withColumn("_load_ts",        current_timestamp())
            .withColumn("_pipeline_run",   lit(self.run_date))
        )

    # ──────────────────────────────────────────────────────────────────────
    # COMBINE + FINALIZE METHOD
    # ──────────────────────────────────────────────────────────────────────

    def _combine_and_finalize_data(
        self,
        txn_df: DataFrame,
        branch_df: DataFrame,
    ) -> DataFrame:
        """
        Enrich transactions with branch metadata and enforce Silver output schema.

        Branch table is broadcast (small, ~500 rows) to eliminate shuffle.
        Both DataFrames are aliased to resolve all column references unambiguously.
        Output column selection explicitly mirrors SILVER_OUTPUT_SCHEMA.

        Args:
            txn_df    (DataFrame): Transformed transaction records.
            branch_df (DataFrame): Branch dimension (branch_id, branch_name, region).
        Returns:
            DataFrame: Schema matches module-level SILVER_OUTPUT_SCHEMA exactly.
        """
        enriched = (
            txn_df.alias("t")
            .join(
                broadcast(branch_df.alias("b")),
                on=col("t.BRANCH_ID") == col("b.branch_id"),
                how="left",
            )
        )
        # Explicit select enforces schema contract — select(*) is never used
        return enriched.select(
            col("t.TXN_ID").alias("txn_id"),
            col("t.CUSTOMER_ID").alias("customer_id"),
            col("t.AMOUNT").alias("amount"),
            col("t.STATUS").alias("txn_status"),
            col("t.TXN_DATE").alias("txn_date"),
            col("txn_category"),
            col("b.branch_name"),
            col("b.region"),
            col("_load_ts"),
            col("_pipeline_run"),
        )

    # ──────────────────────────────────────────────────────────────────────
    # WRITE / OUTPUT METHODS
    # ──────────────────────────────────────────────────────────────────────

    def _write_output(self, valid_df: DataFrame, quarantine_df: DataFrame) -> None:
        """
        Persist Silver records and quarantine records to Delta Lake.

        Args:
            valid_df      (DataFrame): Silver-schema records for main table.
            quarantine_df (DataFrame): Failed-validation records with error_codes.
        Raises:
            RuntimeError: If either write fails (wraps underlying Spark exception).
        """
        # Skip writes in dry-run mode (config flag preserved from CLI)
        if self.config.get("dry_run") == "True":
            logger.info("DRY RUN — skipping write. Valid=%d, Quarantine=%d.",
                        valid_df.count(), quarantine_df.count())
            return

        try:
            valid_df.write.format("delta").mode("append").save(
                self.config["silver_path"]
            )
            logger.info("Wrote %d rows to Silver Delta.", valid_df.count())
        except Exception as exc:
            raise RuntimeError(f"Silver write failed: {exc}") from exc

        if quarantine_df.count() > 0:
            try:
                quarantine_df.write.format("delta").mode("append").save(
                    self.config["quarantine_path"]
                )
                logger.info("Wrote %d rows to quarantine.", quarantine_df.count())
            except Exception as exc:
                raise RuntimeError(f"Quarantine write failed: {exc}") from exc

    def _update_watermark(self, new_wm: str) -> None:
        """
        Persist new high-watermark to shared metadata Delta table.

        Called only after successful Silver write — ensures watermark only
        advances on full success (exactly-once guarantee on retry).

        Args:
            new_wm (str): Maximum LAST_UPDATED value from this run's records.
        """
        wm_df = self.spark.createDataFrame(
            [(self._TABLE_NAME, new_wm, self.run_date)],
            schema="table_name STRING, last_processed_ts STRING, updated_date STRING",
        )
        wm_df.write.format("delta").mode("append").save(
            self.config["watermark_path"]
        )
        logger.info("Watermark updated to: %s", new_wm)

    # ──────────────────────────────────────────────────────────────────────
    # ORCHESTRATOR
    # ──────────────────────────────────────────────────────────────────────

    def run_etl_pipeline(self) -> None:
        """
        Master orchestrator — executes the complete ETL pipeline end-to-end.

        Execution order:
            1. Apply Spark performance configuration.
            2. Read watermark from metadata table.
            3. Extract incremental rows from Oracle (server-side filtered).
            4. Validate: split valid / quarantine records.
            5. Deduplicate valid records on TXN_ID.
            6. Apply business transformations.
            7. Load branch reference for enrichment.
            8. Enrich and select canonical Silver schema.
            9. Write Silver + quarantine Delta tables.
            10. Update watermark (only on complete success).

        Raises:
            Exception: Re-raises after error logging so ADF pipeline
                       activity correctly registers FAILED status.
        """
        logger.info("CustomerTransactionETL START — run_date=%s", self.run_date)
        try:
            self._setup_spark_config()                                  # 1
            last_wm      = self._load_watermark()                       # 2
            raw_df       = self._load_source_data(last_wm)              # 3
            split        = self._process_validate(raw_df)               # 4
            deduped_df   = self._process_deduplicate(split["valid"])   # 5
            transformed  = self._process_transform(deduped_df)          # 6
            branch_df    = self._load_branch_reference()                # 7
            final_df     = self._combine_and_finalize_data(             # 8
                transformed, branch_df
            )
            self._write_output(final_df, split["quarantine"])         # 9
            new_wm = raw_df.agg(spark_max("LAST_UPDATED")).collect()[0][0]
            if new_wm:
                self._update_watermark(str(new_wm))                    # 10
            logger.info("CustomerTransactionETL COMPLETE — run_date=%s", self.run_date)
        except Exception as exc:
            logger.error("CustomerTransactionETL FAILED run_date=%s: %s", self.run_date, exc)
            raise
