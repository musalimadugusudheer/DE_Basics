Role-playing dimensions
One physical dimension table used multiple times in the same fact table, each playing a different role.
In SQL/Spark: CREATE VIEW vw_order_date AS SELECT * FROM dim_date — then join fact to vw_order_date, vw_ship_date, vw_delivery_date separately. One physical table, three logical roles.
